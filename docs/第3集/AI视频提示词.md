## 通用要求（每条提示词后面都可以加上）

```
画面比例 16:9，1080p，色彩明亮，适合小学生观看，镜头平稳，不要出现任何文字、字幕和水印。
```

> AI 生成的莫比乌斯带经常“扭”得不对（扭了一整圈或者没扭）。**生成后请仔细看一遍**：沿着带子看一圈，确认只扭了半圈。不对就重新生成，或者直接用课件第 5 页的 3D 动画。

```
三维卡通风格，一条宽宽的淡紫色纸带扭了半圈后首尾相连，形成莫比乌斯带，悬浮在浅色背景前缓慢旋转。一只可爱的小红蚂蚁沿着纸带中间一直往前爬，爬过扭转的地方后出现在纸带的另一面，继续向前爬，一直不停。柔和光照，画面干净。
```

```
写实微距摄影，桌面上放着一个用白纸做成的莫比乌斯带（纸条扭半圈后粘成的环），一只手拿彩色马克笔沿着纸带中间画线，笔一直不离开纸，线条绕了两圈后回到起点。自然光，浅景深。
```

## 使用小贴士

1. **文件格式**：请用 `.mp4`（H.264 编码），文件名要和表格里**完全一致**（全部小写）。
2. **声音**：建议静音或配轻音乐，由老师现场讲解。
3. **时长**：本集动手环节多，视频总共控制在 1 分钟以内。
4. **自己拍也很好**：用手机拍一段自己剪莫比乌斯带的过程（剪开后变成一个大环），比 AI 视频更真实，也可以命名为 `01-mobius-ant.mp4` 放进去。
