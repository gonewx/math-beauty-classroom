## 通用要求（每条提示词后面都可以加上）

```
画面比例 16:9，1080p，色彩鲜明，适合小学生观看，镜头平稳，不要出现任何文字、字幕和水印。
```

> AI 生成的“分形”往往不够精确。**需要精确的数学图形，请交给课件里的动画**；视频只负责展示真实世界的样子。

## 使用小贴士

1. **文件格式**：请用 `.mp4`（H.264 编码），文件名要和表格里**完全一致**（全部小写）。
2. **声音**：建议静音或配轻音乐，由老师现场讲解。
3. **时长**：本集已经有很多“看”的内容，视频总共控制在 1～2 分钟以内。
4. **预览**：课前打开课件，翻到对应页面，确认右上角出现了“🎬 播放视频”按钮。
