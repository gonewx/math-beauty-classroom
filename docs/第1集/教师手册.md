# 第 1 集《大自然的密码》教师手册

> 适用：小学 4–6 年级 · 时长 40 分钟 · 讲课人：家长志愿者
> 课件：`episodes/ep01/index.html`　学习单：`printables/ep01-学习单.html`　逐页讲稿：[逐页讲稿.md](逐页讲稿.md)

---

## 1. 这节课要让孩子带走什么

1. **一个规律**：斐波那契数列 1、1、2、3、5、8、13……（前两个数相加 = 下一个数）
2. **两个神奇的数**：黄金角 **137.5°**（向日葵种子、叶子的排列）；黄金比 **1.618**（相邻斐波那契数相除越来越接近它）
3. **一种习惯**：看到“黄金比最美”这类说法时，**量一量、算一算、用证据说话**
4. **一个魔术**：回家能给爸爸妈妈表演的加法魔术

## 2. 课前准备清单

### 提前 1 周
- [ ] 和班主任确认：上课时间、班级人数、教室设备（投影 / 触摸一体机 / 电脑系统）
- [ ] 请班主任**提前分好 4 人小组**，每组准备一张“小组名牌”
- [ ] 在家把课件完整走一遍（按 `P` 打开讲者视图，看着讲稿排练，**建议计时排练一次**）

### 提前 1–2 天
- [ ] 打印学习单：每人 1 张，**A4 双面**，打印时选“实际大小 / 100%”
- [ ] 每组准备：彩笔 1 盒（至少 3 种颜色）、直尺 1 把
- [ ] 可选：每组 1 个松果（花鸟市场或网购），或者 1 个菠萝给全班传看
- [ ] 可选：往 `episodes/ep01/videos/` 里放入短视频（见 [AI视频提示词.md](AI视频提示词.md)），不放也完全不影响上课
- [ ] 把整个文件夹复制到 **U 盘**，再在网盘里存一份备份

### 上课当天（提前 15 分钟到教室）
- [ ] 把文件夹复制到教室电脑桌面（不要直接在 U 盘里打开，防止 U 盘被拔）
- [ ] 用 **Chrome 或 Edge** 浏览器打开 `episodes/ep01/index.html`
  - 找不到浏览器？在文件上点右键 →“打开方式”→ 选 Chrome / Edge
  - 学校电脑只有 360 浏览器？切换到“极速模式”（地址栏右侧的闪电图标）
- [ ] 按 `F` 全屏，翻几页，检查**后排能不能看清**字和动画
- [ ] 测试翻页笔（如果有）：按“下一页”能翻就行
- [ ] 如果是**双屏**（电脑屏幕 + 投影）：按 `P` 打开讲者视图，把课件窗口拖到投影屏并全屏，讲者视图留在电脑屏上
- [ ] 如果是**触摸一体机**（如希沃白板）：直接用手指点按钮、拖滑块即可
- [ ] 让课件停在封面页，学生进教室时右侧“向日葵”会自动生长

## 5. 时间不够 / 时间多了怎么办

**超时了（按优先级删减）**
1. 跳过第 11 页“叶子的秘密”（省 1–2 分钟）
2. 第 15 页“量一量”只做演示，不让各组测量（省 2 分钟），把测量改成回家小挑战
3. 第 13 页画螺旋改成回家完成（省 3 分钟）
4. **魔术揭秘和回家小挑战一定要留**——这是学生最期待的收尾

**时间多了**
- 第 6 页接龙再往后接（233、377、610、987……）
- 第 9 页多请几位同学上台找“最好的角度”
- 第 16 页请一位学生当“魔术师”，老师当观众，现场再演一次

## 6. 课堂管理小技巧

- **静音信号**：约定“老师举手，大家举手并安静”，或者按 `B` 黑屏，学生会自然看向你
- **动手前先讲清楚再发材料**：先说“等会儿要做什么”，再让组长拿彩笔，避免讲话时学生在玩材料
- **计时可视化**：动手环节说“3 分钟”，按 `T` 显示计时器
- **鼓励所有答案**：学生猜错时说“好想法！我们来验证一下”，数学课的乐趣在于“猜 → 验证”
- **点名技巧**：用小组名牌轮流点，避免总是同几个学生回答

## 7. 常见意外与应对

| 意外 | 应对 |
|---|---|
| 打开课件一片空白 / 动画不动 | 换 Chrome 或 Edge 打开；360 浏览器切到“极速模式” |
| 画面显示不全或被裁切 | 按 `F` 全屏；若仍然不对，按键盘 `Ctrl + 0` 恢复浏览器缩放 |
| 讲者视图打不开 | 浏览器拦截了弹窗：点地址栏右侧的拦截图标 → 允许。或者直接打印[逐页讲稿](逐页讲稿.md)放在讲台上 |
| 翻页笔翻不动 | 先用鼠标点一下课件画面空白处，让窗口获得焦点 |
| 学生选的数让魔术算错了 | 不会的——无论选什么数，总和一定等于第 7 个数 × 11。若学生算总和出错，全班一起再加一遍，这正好是练习 |
| 电脑彻底坏了 | 打印一份学习单和[逐页讲稿](逐页讲稿.md)备用：兔子问题、找规律、加法魔术、涂螺旋、画螺旋、量一量都可以只用黑板完成 |

## 8. 知识小贴士（给家长）

- **斐波那契**（约 1170–1250），意大利数学家，1202 年在《计算之书》中提出兔子问题，也是把阿拉伯数字介绍到欧洲的重要人物。
- **黄金比** φ = (1 + √5) ÷ 2 ≈ 1.6180339…，相邻斐波那契数之比会越来越接近它。
- **黄金角** = 360° ÷ φ² ≈ 137.508°。向日葵按这个角度排列种子，任何两颗种子都不会落在同一条“射线”上，所以排得最均匀。电脑模拟中只要偏离一点点（比如 137° 或 138°），就会出现明显的空隙或直线。
- **螺旋条数**：向日葵花盘上两个方向的螺旋数常常是相邻的斐波那契数，如 21/34、34/55、55/89（越大的花盘数越大）；松果常见 8/13，菠萝常见 8/13。
- **严谨提醒**：并非所有植物都遵循斐波那契数，这是一种常见的“倾向”；“黄金比最美”“蒙娜丽莎用了黄金比”等说法多数缺乏测量证据。课上已经如实说明，回答学生问题时也请保持这个态度。
- **魔术原理**：设前两个数为 a、b，10 个数依次为 a、b、a+b、a+2b、2a+3b、3a+5b、**5a+8b**、8a+13b、13a+21b、21a+34b，总和 = 55a + 88b = 11 × (5a + 8b) = 11 × 第 7 个数。
