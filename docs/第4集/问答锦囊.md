# 第 4 集《信息的魔法》问答锦囊

> 学生提问时的参考回答。原则：**用孩子听得懂的话说真话**；不会就说“这个问题太棒了，我们一起去查”。

---

### 🔮 关于读心术

**问：如果想的数是 32 或更大呢？**
答：5 张卡片只能管 1～31。想管到 63，就要再加一张“32 号卡片”——每多一张卡片，能猜的数就多一倍。6 张能猜 1～63，7 张能猜 1～127。

**问：卡片上的数是怎么排出来的？**
答：“1 号卡片”放所有 1 号灯泡亮着的数（1、3、5、7……也就是所有单数），“2 号卡片”放所有 2 号灯泡亮着的数，以此类推。你可以自己试着做一套，检查一下对不对。

### 💡 关于二进制

**问：为什么电脑不用我们的十进制？**
答：电脑里的零件是一个个小开关，只有“通电”和“不通电”两种状态，正好对应 1 和 0。用两种状态表示数最简单、最不容易出错。

**问：二进制的 10 是多少？**
答：二进制的 10 就是十进制的 2（2 号灯泡亮、1 号灯泡灭）。有个老笑话：“世界上有 10 种人，一种懂二进制，一种不懂。”

**问：电脑里的文字也是 0 和 1 吗？**
答：是的！每个字都有一个编号，编号再写成 0 和 1。一个汉字通常要用十几到二十几个 0 和 1 来表示。你发的每条消息，其实都是一大串 0 和 1 在网络上飞。

**问：一张照片有多少个 0 和 1？**
答：一张普通手机照片大约有 1000 万个像素，每个像素的颜色用 24 个 0 和 1 记录，加起来有两亿多个 0 和 1！（手机会用数学方法“压缩”，实际存的少很多。）

### 🔐 关于密码

**问：凯撒真的用过这个密码吗？**
答：据古罗马历史学家记载，凯撒确实用“后移 3 位”的方法给将军们写信。那时候很多人不识字，这个简单的密码就够用了。

**问：怎么让凯撒密码更难破解？**
答：可以每个字母用不同的密钥，比如第 1 个字母挪 3 位、第 2 个挪 1 位、第 3 个挪 4 位……这叫“维吉尼亚密码”，曾经几百年都没人能破解。

**问：今天的密码真的破解不了吗？**
答：用现在的电脑，破解手机支付用的密码需要的时间长得不可想象。不过科学家正在研究“量子计算机”，将来可能会威胁到这些密码，所以数学家们也在研究新的、更安全的密码。数学家和“破译专家”的比赛一直在进行！

**问：我的密码怎么设才安全？**
答：不要用生日、123456 这样容易猜的；越长越好，最好混合字母、数字和符号；不同的网站不要用同一个密码；**密码不要告诉别人**（除了爸爸妈妈）。

### 🛒 关于条形码

**问：条形码的黑白条纹是什么意思？**
答：每一个数字都用 7 条“细条”表示，黑的是 1、白的是 0——条形码本身也是二进制！扫描枪读的就是这些 0 和 1。

**问：检查码能发现所有错误吗？**
答：只错一个数字时，它一定能发现。如果同时错了好几个数字，偶尔会“碰巧”对上，但这种情况很少。

**问：二维码也有检查码吗？**
答：有，而且更厉害：二维码就算被挡住或弄脏一部分，还能把丢掉的信息“算”回来。这叫“纠错码”，也是数学家发明的。

### 💬 其他

**问：长大后做什么工作会用到这些？**
答：程序员、网络安全工程师、密码学家、数据科学家……几乎所有和电脑、手机、网络有关的工作都会用到。其实你每天刷卡、扫码、上网，已经在用这些数学了。
