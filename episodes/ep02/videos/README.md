# 第 2 集 · 可选视频文件夹

把视频按下面的文件名放进这个文件夹，课件对应页面右上角会自动出现“🎬 播放视频”按钮（也可按 `V` 键播放）：

| 文件名 | 页面 |
|---|---|
| `01-romanesco.mp4` | 第 6 页 · 身边的分形 |
| `02-coastline.mp4` | 第 13 页 · 海岸线有多长 |
| `03-fractal-zoom.mp4` | 第 14 页 · 无限放大（备用：教室电脑太慢时播放） |

生成视频的提示词见 [docs/第2集/AI视频提示词.md](../../../docs/第2集/AI视频提示词.md)。没有视频也完全可以上课。
