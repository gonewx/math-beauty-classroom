# 数学之美 · 家长进校园系列课

面向**小学 4–6 年级**的互动数学课，由家长志愿者进校园讲授。理念参考吴军《数学之美》：数学不只是算题，而是读懂世界的语言。

- **8 集系列**，每集约 **40 分钟**，每集一个主题，不局限于课本
- 每集包括：开场魔术或游戏 → 三站探索（内置动画 + 动手环节）→ 揭秘与回顾
- 课件是**离线网页**，双击就能打开，不需要联网、不需要安装软件，投影仪和触摸一体机（如希沃白板）都能用
- 页面上的文字全部使用简体中文

## 快速开始（第 1 集）

1. 下载整个仓库（GitHub 页面上点 **Code → Download ZIP**），解压到电脑上
2. 用 **Chrome** 或 **Edge** 打开 `index.html`（系列首页），点“▶ 打开课件”
   或者直接打开 `episodes/ep01/index.html`
3. 按 `F` 全屏，用 `→` / `空格` / 翻页笔翻页
4. 双屏上课时按 `P` 打开**讲者视图**：投影屏放课件，电脑屏看讲稿和计时
5. 打印学习单：浏览器打开 `printables/ep01-学习单.html`，A4 双面打印，每人 1 张

课前请阅读 **[第 1 集教师手册](docs/第1集/教师手册.md)**，里面有准备清单、40 分钟流程表和应急预案。

## 修改与扩展

- **改讲稿**：直接编辑课件里每页的 `<aside class="notes">`，然后运行
  `node tools/export-notes.js episodes/ep01/index.html docs/第1集/逐页讲稿.md "第 1 集《大自然的密码》"` 重新导出
- **加视频**：把 mp4 按 `episodes/ep01/videos/README.md` 里的文件名放进去即可
- **做新一集**：复制 `episodes/ep01/`，修改 `DECK_CONFIG` 里的章节和时间，页面里用 `data-demo="名字"` 引用 `assets/demos.js` 里的动画。已就绪的动画包括：`fern`（巴恩斯利蕨）、`tree`（分形树）、`koch`（科赫雪花）、`chaos`（混沌游戏）、`mobius`（3D 莫比乌斯带）、`caesar`（凯撒密码轮）、`bits`（二进制灯泡）、`magic` / `magicReveal`（读心术卡片）
